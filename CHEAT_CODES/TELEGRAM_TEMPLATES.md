# 📱 Telegram Message Templates

## Status Update
```
🤖 [TIMESTAMP]
✅ Done: [list]
⏳ In progress: [list]
❌ Failed: [list with reasons]
📅 Next: [what's coming]
```

## Help Request (when stuck)
```
🆘 [URGENCY: high/medium/low]
Issue: [what's wrong]
Tried: [what I did]
Need: [what user should do]
Time: [how long]
```

## Daily Report
```
📊 [DATE]
💰 Money today: $X
📈 Traffic: Y visitors
👥 Followers: Z
🆕 New things: [list]
📅 Tomorrow: [plan]
```

## Money Alert
```
💰 MONEY RECEIVED!
From: [source]
Amount: $X
Time: [when]
First $X ever? [yes/no]
```

## Account Alert
```
🚨 ACCOUNT [ACTION]
Account: [name]
Action: [banned/warned/suspended]
Reason: [if known]
Next: [what to do]
```

## Discovery
```
🔍 FOUND SOMETHING
Title: [what]
URL: [link]
Why it matters: [explanation]
Action: [what we'll do]
```

## Question
```
❓ NEED YOUR INPUT
Question: [specific]
Why: [context]
Options:
A) [option]
B) [option]
C) [option]
```

## Success
```
🎉 SUCCESS!
What: [what happened]
Why: [why it matters]
Next: [what's next]
Money impact: [if any]
```
